# واضح | WADEH

بنك رقمي تجريبي بالعربية، فكرته: **التزاماتك الشهرية ما تفوتك.** تسجّل أقساطك وفواتيرك وجمعياتك، وتوصلك تذكيراتها في تقويم الآيفون وعلى شاشة Apple CarPlay وأنت بالسيارة، ورصيدك يظهر في ويدجت على الشاشة الرئيسية، بدون ما تفتح التطبيق.

- **التطبيق:** https://wadeh-lly2.onrender.com (رمز الدخول `123456`)
- **دراسة الحالة (UX Case Study):** [Figma](https://www.figma.com/design/qJjKAEzTGd5scJkjaGuV9N/WADEH-%E2%80%93-Digital-Banking-App?node-id=49-2)

> نموذج تعليمي، كل الأموال والعمليات فيه محاكاة ولا يتصل بأي بنك.

## المزايا

- **الدخول:** رمز مرور من 6 أرقام، أو Face ID على الآيفون والبصمة على اللابتوب (Passkeys حقيقية).
- **نسختان حسب الجهاز:** الجوال بشريط سفلي، واللابتوب بقائمة جانبية ولوحة رئيسية أعرض.
- **التحويل** في 3 خطوات مع الاعتماد بـ Face ID أو البصمة.
- **البطاقات:** مدى وفيزا، مع التجميد وحدود الإنفاق وعرض التفاصيل بعد التحقق.
- **الالتزامات والجمعيات** مع جدول الدفعات وشهر الاستلام.
- **الفواتير، المصروفات، الميزانية، الإشعارات.**
- **يُثبَّت على الآيفون كتطبيق:** Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## التذكير في CarPlay

1. تضيف التزامًا في واضح (مثل قسط السيارة يوم 15).
2. حسابي ← الإشعارات ← مزامنة التقويم ← ربط بالتقويم، فيعطيك الخادم رابط اشتراك `webcal` خاصًا بك.
3. يشترك تقويم الآيفون بالرابط ويحدّث نفسه تلقائيًا.
4. يظهر الموعد في ويدجت التقويم على CarPlay، **باسم الالتزام فقط وبدون مبلغ**.

Apple لا تتيح واجهات CarPlay لتطبيقات البنوك، والتقويم مدعوم رسميًا، فيمر التذكير عبره. شاشة «معاينة CarPlay» داخل التطبيق توضيح للفكرة.

## ويدجت الرصيد

ثلاثة أحجام: صغير (الرصيد)، متوسط (+ الالتزامات القادمة)، كبير (+ آخر العمليات).

1. ثبّت تطبيق **Scriptable** المجاني.
2. في واضح: حسابي ← ويدجت الرصيد ← ربط الويدجت ← نسخ كود الويدجت.
3. في Scriptable: **+** ← الصق الكود ← سمّه «واضح».
4. الشاشة الرئيسية: تعديل ← إضافة أداة ← Scriptable ← اختر الحجم ← Script: واضح.

الرابط للقراءة فقط وخاص بك، ويمكن إلغاؤه في أي وقت، و«إخفاء الرصيد» يخفي المبالغ من الويدجت أيضًا.

## التشغيل محليًا

يحتاج [Node.js](https://nodejs.org) 22.13 أو أحدث، بدون تثبيت أي حزم:

```
node server.js
```

ثم افتح http://localhost:8080 (أو شغّل `start-windows.bat` على ويندوز). الاختبارات: `npm test`.

## الملفات

```
server/   الخادم: الـ API، قاعدة البيانات، التقويم، الويدجت، التحقق الحيوي
public/   الواجهة: الشاشات والتصميم
tests/    الاختبارات
docs/     الشرح التقني (HOW-IT-WORKS.md)
```

## القيود

- حساب تجريبي واحد.
- Apple Pay عرض توضيحي، لأنه يحتاج جهة مُصدِرة معتمدة وتطبيق iOS أصليًا.
- الويدجت يعمل عبر Scriptable، فلا يحتوي أزرارًا (مثل إخفاء الرصيد من الويدجت نفسه)؛ هذا يحتاج تطبيقًا أصليًا.
- الخادم المجاني ينام بعد ربع ساعة: أول فتح قد يأخذ دقيقة، وترجع البيانات للوضع الافتراضي فيلزم إعادة ربط التقويم والويدجت.
